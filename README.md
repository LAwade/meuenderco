# 📦 Projeto Laravel + Vue 3 + Tailwind — Buscador de CEP

Este é um projeto de exemplo utilizando **Laravel (API)** no backend e **Vue 3 + Vite + Tailwind CSS** no frontend, com uma funcionalidade simples de **busca de CEP** via rota `/cep`.

---

## 🧱 Tecnologias

- [Laravel 12](https://laravel.com) (API REST)
- [Vue 3](https://vuejs.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [ViaCEP](https://viacep.com.br/) (serviço de consulta de CEP)
